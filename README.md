
# AWS Static Website Deployment

## Project Overview
A static website deployment project designed to practice AWS cloud hosting and website delivery.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Amazon S3
- Amazon CloudFront
- AWS IAM
- Amazon CloudWatch

## Architecture
Website Files → GitHub → Amazon S3 → CloudFront → End Users

## Key Learning Objectives
- Prepare static website files for cloud deployment.
- Understand S3 hosting and CloudFront content delivery.
- Learn AWS access permissions and basic monitoring.
- Prepare the project for future CI/CD automation with Jenkins.

## Project Status
Application files prepared. AWS deployment and CI/CD automation are pending.
